COMO FAZER O MODELO DIRIGIR O CARRO NO CARLA
=============================================

São três programas rodando ao mesmo tempo, cada um em seu terminal:

  1. CARLA               o simulador
  2. Servidor de direção usa o modelo DeepLabV3+ para decidir a direção
  3. Cliente (Docker)    liga o CARLA ao servidor

O cliente roda em Docker porque a biblioteca do CARLA 0.9.6 só existe para
Python 3.6, e o modelo roda em Python 3.12.


ANTES DE COMEÇAR (só na primeira vez)
-------------------------------------

Você precisa ter:
  - O CARLA 0.9.6 com os mapas off-road em ~/Downloads/CARLA_0.9.6-dirty
  - O modelo treinado em results/deeplabv3+/model.pth
  - O ambiente Python em .venv

Na pasta do projeto, construa a imagem do cliente:

  sudo docker build -t seg-carla-client -f docker/Dockerfile docker

Só é preciso repetir este comando se o docker/Dockerfile mudar.


PASSO 1: ABRIR O CARLA (terminal 1)
-----------------------------------

  cd ~/Downloads/CARLA_0.9.6-dirty
  sh CarlaUE4.sh -opengl -windowed -ResX=640 -ResY=480

Espere cerca de 30 segundos e deixe a janela aberta. O CARLA precisa estar
pronto antes do passo 3.


PASSO 2: INICIAR O SERVIDOR DE DIREÇÃO (terminal 2)
---------------------------------------------------

Na pasta do projeto:

  .venv/bin/python -m modules.driving.server --mode mask --weather ClearNoon --min-speed 2 --max-speed 4

Espere aparecer:

  Servidor pronto em 127.0.0.1:5555. Aguardando o cliente do CARLA...

Também dá para usar o menu:

  .venv/bin/python -m app.main

Escolha a opção 14, digite o clima e digite o modo "mask". Pelo menu a
velocidade é sempre de 1 a 2 m/s.


PASSO 3: INICIAR O CLIENTE (terminal 3)
---------------------------------------

Na pasta do projeto:

  sudo docker run --rm --net host -v "$PWD:/app:ro" -v "$HOME/Downloads/CARLA_0.9.6-dirty/PythonAPI/carla/dist:/carla/dist:ro" seg-carla-client

Deve aparecer:

  Aguardando o servidor de direção...
  Iniciando Offroad_2 com clima ClearNoon

Pronto: o carro começa a andar e a janela do CARLA acompanha o carro.
Uma volta tem 674 m e leva cerca de 3 minutos.


NÃO FECHE NADA NO MEIO DA VOLTA
-------------------------------

Se fechar o CARLA ou o cliente, a execução termina e não conta como volta
completa.


PARA RODAR DE NOVO
------------------

O servidor encerra sozinho no fim de cada execução. O CARLA e o cliente podem
continuar abertos: basta repetir o passo 2 e o cliente reconecta sozinho.

Se o código em carla_client/ mudar, feche o cliente (Ctrl+C) e rode o passo 3
de novo: o cliente só lê o código quando inicia.


OPÇÕES DO SERVIDOR
------------------

  --mode mask          o modelo dirige pela câmera
  --mode waypoint      a rota do mapa dirige e o modelo só é registrado
                       (serve de referência para comparar)

  --weather NOME       ClearNoon, CloudyNoon, WetNoon, WetCloudyNoon,
                       MidRainyNoon, HardRainNoon, SoftRainNoon, ClearSunset,
                       CloudySunset, WetSunset, WetCloudySunset, MidRainSunset,
                       HardRainSunset, SoftRainSunset

  --min-speed N        velocidade mínima em m/s
  --max-speed N        velocidade máxima em m/s

  --no-view-video      não grava a visão de trás do carro (carla.mp4). A volta
                       fica mais rápida, porque o CARLA desenha uma câmera a menos

  --video-speed N      velocidade dos vídeos. O padrão é 2 (duas vezes mais
                       rápido que o carro). Use 1 para ver na velocidade real


ONDE FICAM OS RESULTADOS
------------------------

Cada execução cria uma pasta em results/carla/ com:

  overlay.mp4     o que o modelo vê: a trilha usada em vermelho e os pontos de
                  direção em amarelo
  mascara.mp4     a saída do modelo em preto e branco, antes de qualquer filtro
  carla.mp4       a visão de trás do carro, como na janela do CARLA
  comparacao.mp4  os três vídeos acima lado a lado
  log.csv         dados de cada passo
  summary.json    resumo da execução
  frames/         uma imagem a cada 1 segundo simulado

Os vídeos têm um quadro por passo, então ficam sincronizados entre si. Por
padrão tocam duas vezes mais rápido que o carro (veja --video-speed). A janela
do CARLA roda ainda mais rápido, porque o simulador não espera o relógio: por
isso não adianta gravar a tela.

O campo "reason" do summary.json diz como a execução terminou:

  lap_complete         completou a volta
  collision            bateu
  off_track            saiu da trilha
  stalled              ficou parado
  trail_lost           o modelo perdeu a trilha e o carro parou
  max_steps            atingiu o limite de passos
  client_disconnected  o CARLA ou o cliente foi fechado no meio


PARA ENCERRAR
-------------

  - Terminal 3: Ctrl+C. Se não parar, rode "sudo docker ps" para ver o ID do
    container e depois "sudo docker stop ID".
  - Terminal 2: Ctrl+C, se o servidor ainda estiver rodando.
  - Terminal 1: Ctrl+C ou feche a janela do CARLA.


PROBLEMAS COMUNS
----------------

"O carro não anda"
  Confira se o servidor do passo 2 está rodando. Sem ele, o cliente só espera.

"O servidor terminou logo depois de o cliente iniciar"
  O CARLA ainda não estava pronto. Espere ele abrir, repita o passo 2 e o
  cliente reconecta.

"ERROR: unable to parse the XML string"
  Pode ignorar. Os mapas off-road não têm OpenDRIVE.

"Unable to find image seg-carla-client"
  Falta construir a imagem: veja "Antes de começar".

"error during connect" ou "permission denied" no Docker
  Rode o comando com sudo.
