## Melhores Modelos:
### DeepLabV3
**Prós:**
- Melhor para bordas
- Atual
- Muito eficiente
**Contras:**
- Requer muito poder de processamento
- Pode não ser muito bom para respostas em tempo real

**Modelo desenvolvido pela google**
**Github:** [DeepLabV3](https://github.com/leimao/DeepLab-V3)

### FCN
**Prós:**
- Mais leve
- Amplamente utilizado
**Contras:**
- Mais fraco para contextos mais complexos
- Mais antigo
